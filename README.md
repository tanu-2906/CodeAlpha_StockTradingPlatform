Stock Trading Platform

A Java-based simulated stock trading application developed for the CodeAlpha Java Programming Internship.

Features

Stock market display
Buy and sell stocks
Portfolio valuation and profit/loss tracking
Virtual account balance
Transaction history
Simulated market price updates
Java Swing graphical user interface
File-based data persistence

Technologies

Java
Object-Oriented Programming (OOP)
Java Swing
File I/O and Serialization

How to Run

Open the project in VS Code with Java support and run StockTradingGUI.java.
